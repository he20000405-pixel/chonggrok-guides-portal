      <h2 id="pay">第二步：完成付款并保存订单</h2>
      <p>按页面提示使用支付宝或微信付款。付款后保存订单号、卡密、付款时间和支付记录。银行扣款记录、平台订单状态和产品会员权益是三类不同信息，不能只看到扣款就判断会员已经生效。</p>
      <ul class="check-list">
        <li>确认支付页面中的产品和套餐与目标一致。</li>
        <li>订单完成后不要公开卡密、订单号或付款截图中的个人信息。</li>
        <li>如果支付结果仍显示处理中，先等待订单状态更新，不要重复付款。</li>
      </ul>

      <h2 id="submit">第三步：提交本次服务需要的资料</h2>
      <p>只通过产品页或订单流程指定的入口提交资料。ChongGrok 不要求提供账号密码、短信验证码、邮箱验证码或恢复码。</p>
      <table>
        <thead><tr><th>产品</th><th>资料说明</th><th>提交前检查</th></tr></thead>
        <tbody>
          <tr><td>ChatGPT</td><td>Plus 自助流程使用 session 类凭证；Pro 按客服说明处理</td><td>确认当前登录的是需要升级的账号</td></tr>
          <tr><td>Grok</td><td>使用 Grok User ID</td><td>逐字符核对，避免提交邮箱、昵称或其他账号标识</td></tr>

        </tbody>
      </table>

      <h2 id="verify">第四步：回官方页面验收</h2>
      <p>处理完成后，使用原账号和原登录方式回到产品官方页面，检查会员档位、订阅状态与到期信息。ChatGPT session 类流程完成后，建议退出并重新登录，让旧会话失效并刷新账号状态。</p>
      <ol>
        <li>确认页面显示的是正确账号，而不是另一个邮箱或登录方式对应的账号。</li>
        <li>检查会员名称、状态和有效期是否与订单一致。</li>
        <li>保存验收结果；如有异常，记录页面状态和发生时间。</li>
        <li>订单仍在处理、已经扣款或已有有效订阅时，不要再次购买。</li>
      </ol>
