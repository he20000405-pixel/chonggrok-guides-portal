      <h2 id="services">当前服务范围</h2>
      <p>ChongGrok 当前只围绕 ChatGPT、Grok、Claude 和 Gemini 四类消费者会员订阅提供服务。ChatGPT、Grok、Claude 使用用户自己的账号；Gemini 另有明确分开的成品会员账号业务。</p>
      <p>我们不提供 API 额度、API billing、接码、批量注册或规避平台限制的服务。不同产品的账号状态、地区、付款规则和官方风控都可能影响处理结果。</p>

      <h2 id="password">为什么强调“不需要密码”</h2>
      <p>流程不要求提交账号密码、验证码或恢复码。某些产品会使用 session 或 User ID 等履约资料，它们不是密码，但仍然属于需要谨慎处理的信息。“不要密码”不等于零风险，也不构成保证账号结果的承诺。</p>

      <h2 id="independent">独立第三方身份</h2>
      <p>ChongGrok 是独立服务，不是 OpenAI、xAI、X、Anthropic、Google 或其他平台的官方合作伙伴、代理机构或附属网站。会员功能、价格、额度和地区可用性以产品官方实时页面为准。</p>

      <h2 id="contact">需要咨询或售后</h2>
      <p>产品选择和新订单请进入对应主站页面。已经有订单的用户应准备订单号、卡密、付款时间和脱敏截图，再从主站客服入口联系；不要在公开评论区发布凭证。</p>
