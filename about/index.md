      <h2 id="service">我们提供什么</h2>
      <p>用户可以使用支付宝或微信付款，无需自行准备海外信用卡。ChatGPT、Grok 与 Claude 服务主要使用用户自己的账号；Gemini 的具体账号类型和交付方式以产品页实时说明为准。</p>
      <p>不同产品需要的资料不同。ChongGrok 不索要账号密码、验证码或恢复码；涉及 session 或 User ID 时，只应通过确认的订单流程提交。</p>

      <h2 id="support">售后如何准备</h2>
      <p>如果 ChongGrok 订单没有按预期完成，请先保存订单号、卡密、付款时间、目标账号和脱敏后的页面截图。资料完整时，客服可以更快判断问题属于订单、账号还是产品方权益状态。</p>
      <p>由 Apple、Google Play、X 或产品官网直接收费的订单，应优先联系原计费渠道。已经扣款或交易仍在处理时，不要重新购买。</p>

      <h2 id="scope">服务范围</h2>
      <ul class="check-list">
        <li>提供 ChatGPT、Grok、Claude 与 Gemini 消费者会员相关服务。</li>
        <li>不提供 API 额度、API 充值或 API billing 服务。</li>
        <li>不提供接码、批量注册或规避平台限制的服务。</li>
        <li>不承诺绝对安全、固定完成时间、保证恢复或所有账号均可处理。</li>
      </ul>
