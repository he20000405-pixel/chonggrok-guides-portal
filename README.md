# ChongGrok Guides Portal

Source for the formal ChongGrok brand and knowledge portal:

- Production: `https://guides.chonggrok.com/`
- Hosting: Cloudflare Pages
- Source branch: `main`
- Build command: `bundle exec jekyll build`
- Output directory: `_site`

The portal is a brand, service-boundary, product-routing and knowledge-directory layer. It does not copy the full articles hosted by the existing ChongGrok knowledge hub and product knowledge bases.
